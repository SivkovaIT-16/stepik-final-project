\# Stepik Final Project: UI-автотесты для интернет-магазина



Финальный проект курса Stepik по автоматизации тестирования с помощью Selenium и PyTest.



\## Структура проекта

\- `pages/` — Page Object классы (`BasePage`, `MainPage`, `ProductPage`, `LoginPage`, `BasketPage`).

\- `locators.py` — все селекторы (хранятся отдельно от логики).

\- `conftest.py` — фикстура запуска браузера с параметром `--language`.

\- `test\_main\_page.py` — тесты главной страницы.

\- `test\_product\_page.py` — тесты страницы товара и корзины.

\- `pytest.ini` — конфигурация PyTest (регистрация меток).



\## Установка и запуск



1\. Установите зависимости:

&#x20;  ```bash

&#x20;  pip install -r requirements.txt```

2\. Запустите тесты. По умолчанию используется английский язык интерфейса (--language=en). Флаг -m need\_review запускает только тесты, обязательные для проверки:



&#x20;   ```bash

&#x20;   pytest -v --tb=line --language=en -m need\_review```



\## Важное примечание для рецензентов

Сайт http://selenium1py.pythonanywhere.com/ заблокирован в России на уровне провайдеров (хостинг PythonAnywhere находится на AWS). Для доступа к нему требуется VPN.



Из-за нестабильной работы самого сайта (баг с alert-капчей и сообщением об успехе) некоторые тесты на добавление в корзину помечены маркером xfail. Это сделано намеренно, чтобы тестовый набор оставался «зелёным» и не падал из-за багов на стороне приложения.



Тесты на логин, проверку пустой корзины и отсутствие сообщения об успехе проходят стабильно.
